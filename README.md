# RootKing

RootKing is an Android-focused toolkit project for investigating
and automating supported root procedures for Symphony Z33
(build Z33_HW3_V21).

## Design
- Dark navy and black background
- Neon green and cyan accents
- English-only user interface

## Build
The Android application build will be configured through GitHub Actions.

## Safety
Rooting support depends on device firmware, bootloader state,
and available device-specific methods. Back up important data first.
